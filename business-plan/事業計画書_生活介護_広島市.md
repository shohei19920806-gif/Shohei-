## 2. 事業の目的・理念

### 2-0. コンセプト

> **「働く・出かける・楽しむ・挑戦する。」**
> 障害の程度に関係なく、一人ひとりの可能性に目を向け、成人として地域の中で自分らしく生活するための経験と役割を大切にする生活介護。

成人した利用者が、ただ施設で一日を過ごすのではなく、一人の大人として、自分らしく充実した毎日を送れる生活介護をつくりたい。障害の程度に関係なく、一人ひとりの「できること」「やってみたいこと」「好きなこと」に目を向け、「障害が重いからできない」と決めつけるのではなく、**「この人なら何ができるだろう？」「どうすれば挑戦できるだろう？」**と考えることを出発点にする。

### 2-1. 大切にしたい4つのこと

1. **働く・役割を持つ**：「仕事＝内職」だけで終わらせない。内職・生産活動に加え、掃除・調理・植物の世話・買い物・商品の準備・販売・納品・施設で必要な物の管理など、誰かの役に立つこと、役割を担うことも「仕事」と捉える。
2. **出かける・地域とつながる**：外出は単なるレクリエーションではなく「地域で生活する経験」として位置づける。
3. **楽しむ・遊ぶ**：最初からしっかり余暇の時間を確保する。
4. **挑戦する**：「できない」で終わらせない。無理をさせるのではなく、その人に合わせた小さな挑戦を積み重ねる。

### 2-2. 理念と人員体制の関係(重要な設計判断)

> ⚠️ **経営者レビューで最も強く指摘された点**：週3日の地域外出等をすべての利用者に約束するには、生活支援員4名程度では物理的に不可能である。理念を実現するために必要な人員を、収支が許す範囲でどう確保するかが本計画の核心的な設計課題である。

本計画では、この課題に対して**「平均障害支援区分5(重度対応中心)を基本ケースとし、配置基準(3:1)に基づき生活支援員等6名を確保する」**という方針で応えている(第6章)。区分の重い方を中心に受け入れることで、①基本報酬単価が上がり、②同時に手厚い人員配置が制度上必要になる(＝理念の実現に必要な人員を、報酬構造の中で正当に賄う)という設計である。それでもなお、**週3日の地域外出を全利用者に一律で約束することは避け、当面は個別支援計画に基づき「小グループ制・優先順位づけ」で運用し、職員体制の拡充とともに頻度を引き上げる**、という段階的な目標に改める(下表)。

| 段階 | 地域外出の目標(たたき台) |
|---|---|
| 開所〜1年目 | 希望者を対象に、小グループ(3〜5名＋職員2名)で週1回程度から開始 |
| 2〜3年目 | 職員体制の定着状況を見て、対象者・頻度を拡大(週2回を目標) |
| 4年目以降 | 収支・人員体制の余裕を見ながら、理念に掲げる「週3日程度」に近づける |

**達成できない約束を最初から掲げないこと**が、家族・相談支援専門員からの信頼、そして何より職員の定着にとって重要という指摘を踏まえた変更である。

### 2-3. 曜日ごとに「主活動」を設ける(将来構想)

将来的には曜日ごとに主となる活動を設定することを検討する(全員一律ではなく個別支援と組み合わせる)。

| 曜日 | 主活動の例 |
|---|---|
| 月 | 仕事・生産活動 |
| 火 | 外出・地域活動(対象者を限定した小グループ制) |
| 水 | 仕事・役割活動 |
| 木 | レクリエーション・運動 |
| 金 | 入浴実施日・個別活動 |

### 2-4. 利用者像

**障害支援区分5・6を中心とする重度対応を基本方針**としつつ、生活介護の利用要件(**障害支援区分3以上、50歳以上は区分2以上**)の範囲内で、障害種別を限定せず受け入れる。「区分を問わず」という表現は生活介護の対象者要件に反するため、開所後の運営規程・重要事項説明書では上記の正確な要件で記載すること。「活動的＝身体的にたくさん動ける人」という意味にはせず、重度の方にも、その人なりの仕事・外出・楽しみ・役割・挑戦を見つけていく。医療的ケア(喀痰吸引・経管栄養等)の受け入れ可否は、看護職員の体制(第6章)と照らして**受け入れ可能な範囲を明文化**し、対応できない場合は正直に伝える(できると言って対応できない事業所は、相談支援専門員からの信頼を失い、結果として紹介が途絶える)。

### 2-5. 職員にとっても、笑顔でいられる場所

利用者だけでなく、職員ものびのび働ける職場を目指す。「現場の意見を聞く」「上の人だけで決めない」「意見を聞いたうえで、必要なことはきちんと決める」「決めたことは最後まで取り組む」――**「上から作る施設ではなく、一緒に作る施設」**を基本姿勢とする。

### 2-6. 基本方針(運営面)

1. 障害支援区分5・6を中心とする重度対応を基本方針としつつ、生活介護の利用要件(障害支援区分3以上、50歳以上は区分2以上)の範囲内で障害種別を限定しない「地域のセーフティネット」となる。
2. 個別支援計画に基づき、入浴・排せつ・食事等の介護、創作的活動・生産活動、機能訓練の機会を提供する。
3. 送迎サービスにより、通所が困難な利用者・家族の負担を軽減する。
4. 職員が働き続けられる職場環境(処遇改善加算の最大限活用、研修体制整備)を作り、支援の質と定着率を両立する。

## 4. 市場・地域環境分析

- 広島市は**政令指定都市**であり、障害者総合支援法に基づく指定障害福祉サービス事業者の指定権限が広島市長に属するため、生活介護を含む施設系障害福祉サービスについて**広島市自身が指定権者**となる(広島県ではなく広島市 健康福祉局障害福祉部 障害自立支援課が窓口)。

### 5-1. ガバナンス設計(改訂：経営者レビューを踏まえ新設)

> ⚠️ 経営者レビューで「出資比率・議決権・デッドロック解消・撤退基準が一切ない」ことが最重要懸念の一つとして指摘された。以下を、法人設立前に必ず二人の間で合意し、書面化(創業者間契約書)すること。

- **出資比率(案)**：現場を持つ側が過半を持つ方が、福祉事業では運営が安定しやすいとされる。**丸山氏55〜60%、豊口氏40〜45%**を出発点に協議する(50:50はデッドロックの温床になりやすいため避ける)。
- **重要事項の決裁ルール**：借入・人事(採用/解雇)・設備投資(一定額以上)・役員報酬の変更等、重要事項の決定プロセスと決裁権限を明文化する。
- **現場判断と経営判断が対立した場合の優先順位**：利用者の受け入れ可否、個別の支援内容、職員配置等、**福祉専門職としての現場判断(丸山氏)は、経営判断(豊口氏)に優先する**ことをあらかじめ合意しておく。指定基準上、管理者は従業者及び業務の実施状況を管理する立場であり、この整理は事故・虐待事案の予防の観点からも重要。
- **デッドロック解消・離脱時の取り扱い**：意見が割れた場合の解消方法(第三者を交えた協議等)、一方が離脱・死亡した場合の持分の買取条項を、創業者間契約書に定める。
- **撤退基準(数値で定義)**：例「開所12か月後に契約者○名未達、または累積損失が○○万円を超えた場合、事業の縮小・譲渡・撤退を協議する」。撤退基準を持つ計画は、金融機関からの信頼を得やすい。
- **会長の位置づけ**：主要な資金提供者になる以上、実質的な影響力を持つ。**債権者(貸付)なのか、出資者なのか、経営顧問として関与するのかを明確化し、書面化する**(第9章)。

### 7-3. 法令適合チェックリスト(新設：経営者・審査担当者双方から必須指摘)

物件を**契約する前に**、以下を必ず確認する。「契約してから用途変更できないと判明」は業界で最も多い失敗の一つ。

- [ ] **用途変更確認申請の要否**：生活介護事業所は建築基準法上「児童福祉施設等」に区分される特殊建築物。**延床200㎡超の部分を用途変更する場合、原則として建築確認申請が必要**(平成30年建築基準法改正・令和元年6月25日施行)。ただし、**転用元が「類似の用途間」(例：老人デイサービスセンター等、同じ「児童福祉施設等」区分内での用途変更)に該当する場合は確認申請が不要**となる場合があり(建築基準法施行令第137条の18)、居抜き物件の転用元によって要否が変わる。**必ず建築士に個別判定を依頼すること。**200㎡以下でも建築基準法・消防法の実体規定(採光・内装制限・避難経路等)は適用される。
- [ ] **検査済証の有無**：既存建物に検査済証がない場合、用途変更(確認申請)が極めて困難になる。物件選定の初期段階で必ず確認。

### 10-5. 「立ち上がり期」と「成熟期」の切り分け(新設：事業モデルの潜在力を確認する試算)

第10-3章の5ヵ年計画は、契約者数がゼロから積み上がる**新規開業特有の立ち上がり期(Year1〜3)**を含んでいる。そこで「立ち上がり期を終えた後の成熟期だけを取り出したら、事業モデルそのものに稼ぐ力があるのか」を切り分けるため、別紙Excel新設シート「成熟期シナリオ」で試算した。5ヵ年計画・資金計画(第9・10-3章)を置き換えるものではなく、補助的な確認用の試算である。

| 成熟期稼働率(仮定) | A. 理念優先(7.4名＋加算Ⅲ、採用中の方針) | B. 法定最低ライン(6.0名、加算Ⅲなし・参考) |
|---|---|---|
| 85%(現行計画のYear5と同水準) | ▲557万円(現行計画Year5と完全に一致) | ▲168万円(第10-4-2章のコスト圧縮シナリオと一致) |
| 90% | ▲224万円 | **+117万円** |
| 95% | **+109万円** | **+402万円** |

**「立ち上がり期を除けば必ず黒字」と単純には言えない。**Aの人員配置(理念優先)を維持したまま黒字化するには、稼働率を85%からさらに引き上げる(概ね93%前後が目安)必要がある。一方、Bの法定最低ラインであれば、90%程度の現実的な稼働率で黒字化する。

**それでも、この試算から言えることは2点ある。**

1. **事業モデル自体が恒常的な赤字体質とまでは言えない。**少なくとも法定最低ラインの人員配置であれば、90%程度の稼働率で黒字化する経済性を持っており、生活介護という制度・単価構造そのものが赤字前提というわけではない。
2. **本計画の本当の課題は「事業モデルが稼げるか」ではなく、「稼働率をどこまで・どれだけ早く引き上げられるか」(第4章、現時点で未着手)と「それまでの立ち上がり期をどう乗り切る資金を確保するか」(第9章)である。**第9-2章の約6,465万円の資金ギャップは、事業が恒久的に赤字を垂れ流すためではなく、**この立ち上がり期を乗り切るための橋渡し資金**として理解すべきものである。

> ⚠️ 成熟期稼働率(85%/90%/95%)自体もすべて仮定であり、佐伯区・西区の実際の需給(第4章、未着手)で確定させる必要がある。既存の同業他社が実際にどの程度の稼働率で運営しているかも、現地調査・ヒアリングで確認すべき項目である(第13章)。

| 障害福祉サービス等情報公表制度への報告 | 事業所情報の公表・年次報告 | 情報公表未報告減算 | 指定後、報告期限まで |
| 非常災害対策 | 消防計画の届出、避難訓練の実施 | 消防法上の義務違反 | 指定申請まで |
| 苦情解決体制 | 苦情処理担当者・第三者委員の設置、重要事項説明書への明記 | 運営基準違反 | 指定申請まで |
| 協力医療機関の確保 | 緊急時対応のための医療機関との連携 | 運営基準違反 | 指定申請まで |
| 記録の整備 | サービス提供記録等の5年保存 | 運営基準違反 | 開所後、継続的に |
| 就業規則・給与規程等 | 常時10名以上雇用の場合は労基署への届出義務 | 労働基準法違反 | 開所前後、要件充足時 |
| **個別支援計画の作成・モニタリング体制** | アセスメント→個別支援計画原案→担当者会議→本人・家族への説明・同意→交付→**6か月ごとのモニタリング**という一連の手順を、利用者数分(定員20名)確立する。生活介護の運営基準の中核であり、サービス管理責任者(丸山氏)の実務負荷の中心になる(第6-5章) | **個別支援計画未作成減算**(所定単位数の30%、3か月以上継続で50%という大幅な減算) | 指定申請〜開所後、継続的に |
| サービス管理責任者の欠如への備え | 丸山氏が管理者を兼務する一極集中体制であるため、不在・休職時の代替体制をあらかじめ検討しておく | **サービス管理責任者欠如減算** | 開所前に体制を検討 |
| 生活支援員等の欠員への備え | 常勤換算が法定最低ラインに近い場合、1名の退職・長期休養で基準を割り込むリスクがある(第6-5章の非常勤登録リスト等) | **サービス提供職員欠如減算** | 継続的に |
| 定員超過利用への対応 | 1日の利用者数が定員の150%を超える場合、または直近3か月平均が125%を超える場合の減算ルールを把握し、契約者数の運用上限を管理する | **定員超過利用減算** | 開所後、継続的に |
| 処遇改善加算の体制届・実績報告 | 加算の区分に応じた体制届出書の提出、賃金改善計画書・実績報告書の作成(第10章で加算収入と同額を人件費に計上している前提の履行) | 未届出・未達成の場合は加算の返還 | 指定申請時、以後毎年度 |
| 利用者負担額の受領・領収証交付、実費徴収の同意 | 食費実費(外部委託費)等を徴収する場合、重要事項説明書・契約書への明記と個別の同意取得が必須 | 運営基準違反 | 指定申請まで |
| 事故発生時の対応・市への報告 | 事故発生時の対応マニュアル整備、広島市への報告手順の確立 | 運営基準違反 | 指定申請まで |
| 欠格事由の確認 | 法人代表・役員(丸山氏・豊口氏)について、障害者総合支援法第36条第3項の欠格事由(禁錮以上の刑、指定取消しからの5年経過等)に該当しないことの確認 | 指定を受けられない | 申請前に確認 |

上記を「第13章 今後のアクションプラン」に落とし込み、担当者と期限を割り当てること。特に**個別支援計画関連の体制整備は生活介護の運営基準の中核**であり、他の項目より優先して具体化すること。

## 12. リスクと対応策

| リスク | 内容 | 対応策 |
|---|---|---|
| **収支構造リスク(最重要)** | 人員配置体制加算Ⅲの段階導入(第10-4-1章)を反映しても、Year5時点で年間約557万円の営業赤字が残る | 第10-4章の論点(重度障害者支援加算Ⅲ・稼働率・固定費・多機能型化)を検証し、次版までに黒字化(または赤字許容可能な水準への縮小)の道筋を明確にする |
| **資金ギャップリスク(最重要)** | 5ヵ年の累積資金需要を踏まえると、現時点の調達計画で約6,465万円の資金ギャップが残る(第9-2章) | 重度障害者支援加算Ⅲ等の残る加算取得を優先的に反映したうえで、居抜き物件の徹底活用、自己資金の積み増し、会長借入・地方銀行融資の増額交渉、多機能型化を組み合わせて解消する |
| 平均障害支援区分低下リスク | 収支の生命線は平均区分5の維持。区分4台に落ちるだけで基本報酬収入が3割前後減少し得る一方、人員体制はすぐには縮小できない | 「区分5・6の利用者を一定数以上維持する」運用ルールを明文化し、幅広い受け入れ方針(第2-4章)との両立を図る。平均区分は前年度実績で毎年度判定され、変動時は変更届が必要 |
| 自己資金過少リスク | 自己資金が薄く、金融機関・会長への説明で本気度を疑われやすい | 丸山氏が事業に専念する姿勢、豊口氏が経営責任を持つ体制、具体的な返済計画(第9章)を明示。開業後は役員報酬を抑制し返済を優先する方針を共有 |
| 看護職員・機能訓練指導員の確保リスク | 必置(または運営規程上必須)の職種だが、現時点で候補者のあてがない | 開所6か月以上前から採用活動を開始。非常勤の組み合わせでの充足も検討 |
| 稼働率未達リスク | 開所直後は利用者確保に時間がかかる。現時点で確定した紹介ルートはまだない | 特別支援学校の進路決定サイクルに合わせた開所時期の調整、相談支援事業所への早期からの営業活動(第4章) |
| 経営体制・ガバナンスリスク | 丸山氏(現場)と豊口氏(経営)の意思決定の分担が曖昧だと運営が滞る | 第5-1章の出資比率・決裁ルール・撤退基準を創業者間契約書として明文化する |
| 物件確保・法令適合リスク | バリアフリー改修可能かつ用途変更・消防法令に適合する物件が見つかるとは限らない | 居抜き物件を優先探索し、建築士・消防署予防課への事前相談を物件内見と同時並行で進める(第7章) |
| 報酬改定リスク | 3年に一度の報酬改定で単位数・加算要件が変動する(次回は2027年度が目安) | 複数シナリオでの収支試算、加算取得率の高い運営体制の構築 |
