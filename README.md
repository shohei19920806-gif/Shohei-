# 生活介護事業 開設 事業計画

広島市での生活介護事業所開設に向けた事業計画一式です。

## 収録ファイル (`business-plan/`)

| ファイル | 内容 |
|---|---|
| `事業計画書_生活介護_広島市.md` | 事業計画書の本文(Markdown版・レビュー用ドラフト) |
| `事業計画書_生活介護_広島市.docx` | 事業計画書の本文(Word版・金融機関/会長への提出想定) |

## 体制

- **丸山氏**：サービス管理責任者資格保有・現場責任者
- **豊口祥平氏**：丸山氏の元上司・経営責任者(法人経営・資金調達・外部交渉)

## 現状のステータス

ヒアリングおよび丸山氏作成の構想書・会長向け補足資料(想定問答・返済プラン)をもとにした「たたき台」です。以下は今後、現地調査・行政窓口への確認・専門家レビューを経て確定させる必要があります。

- 開設候補エリア(佐伯区・西区)での物件確定
- 広島市 障害自立支援課への事前相談結果の反映
- 最新の障害福祉サービス等報酬告示による単位数・加算率の確認
- 会長への借入提案(金額・金利・返済条件)の確定
- 金融機関(日本政策金融公庫等)との融資条件の確定

詳細は `事業計画書_生活介護_広島市.md` の第12章「今後のアクションプラン」を参照してください。
