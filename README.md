# 生活介護事業 開設 事業計画

広島市での生活介護事業所開設に向けた事業計画一式です。

## 収録ファイル (`business-plan/`)

| ファイル | 内容 |

| `事業計画書_生活介護_広島市.md` | 事業計画書の本文(Markdown版・レビュー用ドラフト) |

## 現状のステータス

代表者へのヒアリングに基づく「たたき台」です。以下は今後、現地調査・行政窓口への確認・専門家レビューを経て確定させる必要があります。

- 開設候補エリア・物件の確定
- 広島市 障害自立支援課への事前相談結果の反映
- 最新の障害福祉サービス等報酬告示による単位数・加算率の確認
- サービス管理責任者候補の確保状況
- 金融機関との融資条件の確定

詳細は `事業計画書_生活介護_広島市.md` の第12章「今後のアクションプラン」を参照してください。
